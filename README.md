# Gate Surfers Assets

Public download pack for **GATE SURFERS 『蒼門』**.

## Prompt assembly (FRAME)

See **[FRAME.md](FRAME.md)** — the single structure for every generation:

```
[ANCHOR]  Visual Bible §1, verbatim
F FOCUS   Locked character or prop block
R REGION  Where (§10)
A ANGLE   Camera
M MOOD    Light & color (§3–4)
E EFFECT  Heavy ink, hard two-tone
[NEGATIVE] §2 global + block EXTRA
```
